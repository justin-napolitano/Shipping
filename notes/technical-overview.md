This repo analyzes global shipping patterns and data. I focus on extracting insights into shipping trends and logistics. It's designed to be modular, so you can easily add new data sources for analysis.

## Key Components
- **Tech Stack**: Written in Python (but could be in R), utilizing libraries like pandas and matplotlib for data processing and visualization.
- **Project Structure**:
  - `data/`: Contains the shipping data.
  - `notebooks/`: Jupyter notebooks for analysis.
  - `src/`: Source code for processing.
  - `outputs/`: Generated reports and visuals.

## Getting Started

To try it out:

```bash
git clone https://github.com/justin-napolitano/Shipping.git
cd Shipping
pip install -r requirements.txt
python main.py
```

### Gotchas
- Ensure you have the right Python version and dependencies installed. Check `requirements.txt` for specific packages needed.
